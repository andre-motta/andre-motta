## What I work on

- **Software foundations:** Python packaging, source builds, dependency compatibility, and release systems that make failures easier to understand.
- **Accelerator ecosystems:** Building and validating software across CPU, CUDA, and ROCm environments.
- **Agentic engineering:** Sandboxed coding agents, observable CI workflows, and tools that help engineers review and direct their work.
